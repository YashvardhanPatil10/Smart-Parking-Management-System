# Smart Parking Management System 🚗

## About Project

This is my mini project based on parking system.

The main idea of this project is to reduce time waste while finding parking and manage parking in a simple way.

---

## How it Works

This project has 2 logins:

### 1. Admin Login

Admin controls the system.

Admin can:

* Set number of parking slots
* Set price per minute
* Set minimum charge
* See total revenue
* Check overall parking report

---

### 2. Dashboard (User Side)

This is used when vehicle comes for parking.

Here we can:

* Enter vehicle number
* Select vehicle type (car, bike, etc.)
* Set priority of vehicle
* Assign parking slot
* Timer starts automatically after slot is assigned

When vehicle leaves, parking cost is calculated based on time.

---

## Features

* Simple parking slot management
* Time-based cost calculation
* Separate admin and user system
* Helps in reducing time wastage
